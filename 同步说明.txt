山海残卷 · 本地与 GitHub 双向同步
================================

当前工作目录：C:\GAMEbyDeepseek
GitHub：https://github.com/DA0C1/GAMEbyDeepseek

【怎么同步】
当前已配置后台自动双向同步，并设置登录 Windows 后自动启动。
本地文件修改停稳 5 秒后自动保存并上传；每 30 秒检查 GitHub 更新并合并到本地。
没有修改时不会创建空提交。后台运行不需要打开 Codex 或同步窗口。
「启动自动同步.cmd」：开启后台同步，同时启用登录自动启动。
「停止自动同步.cmd」：等待本次同步完成后停止，并取消登录自动启动。
「查看同步状态.cmd」：查看最近成功时间和当前状态。
「双向同步.cmd」：立即手动同步一次，可与后台同步共用。

【以后在哪里修改游戏】
请修改本目录下「山海残卷」里的文件。
桌面的旧目录保留为归档，不会自动与这份工作目录互相复制。
游戏源码、素材、说明和工具通过 GitHub 同步。
node_modules、测试临时文件、dist 打包产物不提交；成品 HTML 可由源码重新构建。
浏览器中的个人进度和正在进行的对局不属于 Git 文件，不随仓库同步。

【启动游戏】
进入「山海残卷」，双击「启动游戏.bat」或「启动AI测试版.bat」。
本机已在该目录的 dist 中放入当前普通版与 AI 版单文件 HTML，可直接打开。
详细操作和更新记录见「山海残卷\README.txt」。

【出现冲突或失败】
两边修改了同一段内容时，同步会暂停并保留双方内容，弹出一次提示，不强制覆盖。
处理冲突并完成合并后，后台会自动恢复同步。
网络或登录失败会保留本地内容，稍后自动重试；具体原因记录在 .game-sync\sync.log。
需要帮助时，把同步状态或日志发给我即可。

【命令行用法】
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Sync-Game.ps1
可用 -Message "本次修改说明" 自定义提交说明。

【开发验证】
在仓库根目录运行：
  node tools/sync-check.cjs
  node tools/auto-sync-check.cjs
分别验证一键同步与后台自动同步。检查使用临时仓库，不修改真实 GitHub 游戏项目。

同步需要 Git。脚本会寻找已安装的 Git，或本机 Codex 附带的 Git。
后台运行还需要 Node.js 22 或以上版本，同样支持本机 Codex 附带的运行环境。
GitHub 登录沿用系统凭据，不在项目文件中保存密码或令牌。
