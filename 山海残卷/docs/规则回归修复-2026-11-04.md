# 2026-11-04 规则回归修复记录

基线：`d72e61faddb34ade5edeae1f10387683d6403d8e`。本轮为本地修复候选；没有推送、合并或部署远端，没有访问玩家的浏览器存档。现有美术保留，本轮优先修复影响决策和结算的规则问题。

## 已复现并修复

1. **天命跨战斗残留**：旧实现直接修改永久 `energyMax`。现在使用战斗增益，下一战重置，同时保留破卷永久奖励。战斗 HUD 与 AI 状态使用同一有效上限。
2. **蚀骨没有扣血**：现在结束回合时，每张仍在手中的蚀骨失去 2 点生命，无视护甲，可致死，死亡后不会开启敌方回合。被万法归一等效果提前弃掉时不扣血；回合末法宝已取得胜利则不再追加伤害。
3. **万法归一少算一张**：伤害预览已经移走正在打出的牌，旧段数公式又减了一次。现在 0/1/2/5 张剩余手牌的预览与实际伤害一致，预览不改手牌。
4. **追魂错误触发**：过去只检查本回合攻击牌数，先打磨剑仍会获得首牌抽牌奖励。现在独立记录本回合总出牌数，并在新回合重置。
5. **火系法宝反过来增强敌人**：朱雀羽、焚天炉、焚天套装不再提高玩家承受的灼烧层数/伤害，敌人施加灼烧也不再触发离焰抽牌。对敌人的加成不变。
6. **太极持续过久**：旧实现把 8 点反击伤害当作 8 回合时长。现在反击覆盖完整敌方回合，然后清除；同回合多次减伤也不会额外延长到之后的回合。
7. **九尾扫连击预览偏低**：原来显示 5×2，但第一击施加易伤后第二击实际为 8。现在显示 5+8，AI 同时提供每段数组与总额。已有易伤、虚弱和减伤仍按实战顺序计算。
8. **群攻重复计算首击法宝**：赤金印/断刃只在实际站位顺序中的首击生效，预览不再给每一个目标都加一次；覆盖横扫、万剑归宗与万法归一的多目标情况。
9. **不确定攻击误标必杀**：五雷正法对多个目标随机分配时显示“≤”及“随机分配”，有闪避/幻影的目标提示可能闪避，不再显示确定的“斩”。不同段的伤害不相同时，摘要显示段数而不是错误地把第一段乘以总段数。
10. **展卷转场可重复开局**：320ms 按钮防抖短于转场，重复点击可能计数两次并覆盖首次序章。现在转场只允许开始一次，锁住导航，返回标题后可正常再开局。
11. **歇脚回复量虚高**：显示值改为使用实际治疗预览，包含天命 4/5 的 0.85 系数以及当前缺血量；选择后不会再次重复扣减系数。
12. **要诀护甲时机错误**：说明改成“护甲在下回合开始时清零”，与实际防御完整敌方回合的规则一致。

## 验证限制与下次检查

`npm run test:browser` 与 `npm run test:interactions` 已尝试启动 Chromium，但在启动游戏前失败：`socket() failed: Operation not permitted`。使用可写的独立 HOME 并获准重试后结果相同。当前执行环境不支持浏览器所需的进程套接字；这不是游戏断言失败，也不能算浏览器通过。

`npm run test:portable` 需要同一种浏览器能力，本轮未运行。静态打包检查不能证明图像布局、音频解码、真实鼠标交互或完整通关正确。在可用的 Chromium/Edge 环境中应继续执行这三项浏览器检查，并重点查看天命灵力显示、5+8 意图文本、随机伤害提示、标题连续点击和歇脚治疗。

这些预览仍以当前状态为依据。敌人之间先后施加的状态、随机选择与闪避、反伤或击杀触发的连锁效果可能改变最终结果；本轮没有宣称穷尽所有法宝与牌组组合，也没有重跑三卷完整浏览器实玩。
