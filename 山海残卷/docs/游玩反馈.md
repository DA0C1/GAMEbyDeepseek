# 游玩反馈与修复

## 已修复

- 牌组关闭方式不明确：地图与战斗统一使用牌组浮层，增加右上角「关闭 ×」、右下角「返回游戏」和 ESC 提示。
- 满页牌组布局溢出、关闭按钮与分页区域重叠：重新安排三行卡牌与独立的分页、关闭区域；保留铭刻纹理。
- 怪物死亡后背景光圈与地面阴影残留：立绘、光晕、属性灵光、阴影、选中圈和初见文字一起淡出、销毁；死亡目标停止接收点击与界面刷新。
- 剧情期间误触战斗牌：开场定时器不再覆盖对话输入锁，所有战斗输入统一检查浮层状态，对话与牌组浮层阻止点击传到战斗/地图；打开浮层时取消选牌和拖拽。
- 药师葫芦未回血、铜钱串未加墨：胜利时补调用法宝胜利钩子，一场只结算一次，沿用原有治疗上限和天命减益。
- 原启动器固定引用 `D:\Projects\ShanhaiScrolls`：改为当前目录，提供无需额外运行依赖的本地服务。

## 保留与限制

- 保留用户本地版本已有的 HiDPI 世界坐标修复。
- 本次未重制画面与战斗平衡，也未重打包旧 EXE。可由源码重新生成单文件 HTML。
- 游戏主要通过 Canvas 绘制，卡牌与按钮缺少完整的无障碍语义；这会增加辅助操作难度，需要后续单独设计。
- 新增独立 AI 测试版，以 HTML 侧栏补充可读取状态与具名控件，另有固定规则种子和四个问题复现入口，详见 `AI测试.md`。

## 验证

6 项逻辑回归与 9 组浏览器检查通过，包括 49 张牌组分页、关闭按钮与 ESC、死亡视觉对象销毁、开场与最后一句对话隔离、葫芦/铜钱结算、高分屏交互、AI 侧栏操作与种子复现。另提供普通版和 AI 版单文件打包检查：`npm run test:portable`（先完成两个打包命令）。

此前 AI 子代理存在阶段完成后自行停止、浏览器窗口接口无法确认网址、进度汇报延迟等问题，属于自动化执行与监督问题，未通过修改游戏规则来规避。
