# 协作约定

本项目由三位共创者共同维护。为避免互相覆盖，改动请遵循以下约定。

## 1. 改之前先对齐

- 先运行 `python tools/sync_repo.py`，看是否有「远端领先（SKIP-REMOTE-AHEAD）」的文件。
- 有的话，先把远端版本合并进来，再动手。
- 不要整文件复制覆盖别人刚改过的内容。

## 2. 提交信息写清楚

格式：

```
type(scope): 一句话说明

改了什么：
- ...

为什么改：
- ...

影响文件：
- src/...
```

`type` 用 `feat` / `fix` / `docs` / `refactor` / `test` / `chore`。
同步脚本会自动在正文追加本次实际改动的文件清单和同步基线。

## 3. 同步脚本

- `python tools/sync_repo.py`：只检查，不改远端
- `python tools/sync_repo.py "说明" --push`：只推送安全改动
- 脚本会检测「远端和本地都改过同一文件」并中止，不会静默覆盖
- 默认只新增/修改，不删除远端文件（除非显式 `--delete`）

## 4. 冲突处理

- 冲突文件先人工合并，保留双方意图，再推送。
- 不确定时先沟通，不要用 `--force` 硬覆盖。

## 5. 改完自检

- 逻辑改动：`npm test`
- 浏览器行为：`npm run test:browser`、`npm run test:interactions`
- 单文件产物：`npm run build:single`

## 6. 不要提交的东西

- `node_modules/`、`dist/`、`test-artifacts/`、`release/`
- 本机凭据、token、绝对路径配置
