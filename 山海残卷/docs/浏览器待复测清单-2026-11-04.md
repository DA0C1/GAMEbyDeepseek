# 浏览器待复测清单 · 2026-11-04

本轮已完成规则模块、场景方法、布局边界、HTTP 服务和单文件内嵌校验。当前执行环境无法启动 Chromium，因此以下项目**仍待在真实浏览器完成**，不是已经通过的验收记录。

## 准备

- 保留正在玩的浏览器窗口和个人存档。使用独立测试浏览器配置或无痕窗口，并从 AI 测试入口的独立端口开始。
- 在 `山海残卷` 目录运行 `npm ci`，然后运行 `npm test`。
- Windows 可运行 `npm run test:browser`、`npm run test:interactions`。脚本默认使用常见位置的 Edge；自定义安装位置使用 `EDGE_PATH` 环境变量。
- 运行 `npm run build:single`、`npm run build:ai`、`npm run test:portable-static`，再运行 `npm run test:portable`。静态校验不能代替最后的浏览器测试。
- 这些浏览器脚本使用单独启动的测试浏览器。手动测试 AI 场景会建立新测试局，不要在保存个人进度的普通版端口执行。

## 手动验收重点

1. **首次声音与静音**：加载完成后第一次点击/按键应有音效。标题淡入时把音乐降到零，等淡入结束仍须静音。连续切换地图、事件、鬼市，音乐不应永久停在极低音量或重叠播放。最后实听首领阶段警示音。
2. **暂停与浮层**：敌方攻击前按 ESC 暂停，等待数秒，血量与战斗回合不应变化。从暂停打开要诀，鼠标应能点击“知道了”；关闭后提示文字不能残留。设置关闭后仍回到暂停菜单。首领进场立即按 ESC，再打开要诀或牌组时，开场对话必须等浮层关闭后再显示，不能藏在暂停层后。
3. **窗口缩放**：在加载中、地图、战斗分别调整窗口大小；再打开设置、调整大小、返回。被暂停的原场景应保持居中，文字与点击位置一致。
4. **重叠手牌**：悬停左侧牌让它抬起，点击覆盖邻牌的区域，应选中视觉最上方那张。拖拽过程中不应被旧悬停动画拉回；取消后预演消失，再悬停能重新抬牌。点击选中牌后移走鼠标，牌仍保持选中姿态。已选攻击时点击盖住敌人下沿的另一张手牌，不应误向背后敌人出牌。
5. **回响与弃牌**：无抽牌的回响铭刻牌打出后，应留下可继续使用的新手牌视图。第二次打出正常离手。结束回合后旧牌立即离开，抽/弃/耗计数同步，迷惑进入消耗堆。
6. **费用显示**：获得五行轮后，第一张有实际费用的普通牌显示减少一费。出牌后剩余牌费用恢复，下回合再次减费。轻铭刻和免费牌不浪费减费；X 牌仍显示 X。
7. **预演同步与排版**：选中攻击牌后用大力散、腐骨水或无墨之水，预演立即变化。赤霄散击杀目标后，不再显示该目标的旧预演。三敌、多段、成势、护甲与随机说明应换行且互不遮挡；随机示例不能标必杀。
8. **首领意图**：给首领施加中毒/灼烧，再将血量压到下次持续伤害会跨越二阶段的边缘。头顶应预告新阶段实际动作；持续伤害足以击杀时标“将亡”。前序敌人的动作仍可能改变结果。同伴治疗后，已不再致死或换阶段的意图应立即恢复。
9. **终态**：低血量攻击带反噬的敌人后，若玩家死亡，不得继续击杀后续目标、回血或回响回手。战败与主动放弃的伤害/出牌统计应包含最后一场且不重复计入。
10. **商店与歇脚**：连续点升级与铭刻只能出现一个选择层；取消可重开。擦符时不能并行购买，选择后不会负墨。购买铁算盘后，未售商品立即按原价七五折，不对已付款项追溯减价。
11. **事件与转场**：残血选择需要失去生命的事件，致死后不应靠法宝/残页奖励复活。快速连点“展卷”“入卷”“再入卷”不应创建多局或多张地图。地图引言出现前的短暂淡入也不能先选路线。
12. **说明与图鉴**：检查焚墟和其他长描述是否完全位于卡面文字区；升级象数应说明额外抽牌。新发现法宝/药水/卡牌后刷新测试页，见闻不丢失。标题最远进度应显示卷与层，而非把内部编码当连续楼层。
13. **状态与立绘**：多种能力和减益同时存在时，左上状态分行而不遮住药水，共鸣文字仍在底衬内；暂停按钮完整可见。朱雀羽/焚天炉增加灼烧时提示实际层数，爆炎显示已清除。首领二阶段原画保持自身比例；连续触发反噬/卸力后，短促放大应恢复原尺寸，不能越变越大。白鵺群体治疗仅显示真实恢复量，满血目标不显示虚假的 +10。
14. **奖励与成势**：快速反复移入移出奖励卡面，卡牌应恢复固定大小，不累积变大。五行成势出现淡色薄光并很快消失，不应成为不透明闪屏，也不影响之后的原生受击闪光。
