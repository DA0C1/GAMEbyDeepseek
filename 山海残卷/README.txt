山海残卷 · SCROLLS OF SHANHAI
========================================

一款水墨风格的卡牌构筑 roguelike。
你是守卷人，执半枚残印入卷，逐卷修补《山海图》，
封印逃逸的异兽。

【怎么开始】
  下载完整仓库，进入本 README.txt 所在目录。
  安装 Node.js 22 或以上版本（普通版也支持 Python 3），
  然后双击「启动游戏.bat」，自动启动服务并打开：
    http://127.0.0.1:8899/index.html
  运行游戏不需要安装 npm 依赖。

  源码入口使用 ES Modules，必须通过 http:// 打开，
  直接双击源码 index.html 会被浏览器拦截。
  打包后的单文件 HTML 可直接双击打开，包含引擎、图片和音乐。

【本地与 GitHub 自动同步】
  本机新工作目录为 C:\GAMEbyDeepseek；以后修改这份目录里的游戏文件。
  仓库根目录「启动自动同步.cmd」会开启后台同步并设置登录后自动启动。
  本地修改停稳 5 秒后自动上传，每 30 秒获取 GitHub 更新。
  「停止自动同步.cmd」会停止后台并取消登录启动；「查看同步状态.cmd」显示当前结果。
  冲突时保留双方内容并暂停，处理完成后自动恢复；网络失败稍后自动重试。
  源码、素材和说明通过 Git 同步；浏览器个人存档和 dist 等忽略文件不上传。
  详情见仓库根目录的 同步说明.txt；桌面旧目录保留为归档，不自动互相复制。

【操作】
  鼠标点击卡牌    选中（攻击牌需再点敌人）
  鼠标拖拽卡牌    拖到敌人身上直接打出
  结束回合        右下角按钮
  ESC             返回/关闭面板

【玩法】
  初始每回合 3 点灵力、抽 5 张牌。
  法术牌直接生效，攻击牌要指定目标。
  护甲每回合清零，状态会持续若干回合。
  敌人头顶的图标是它下回合要做的事——先看清再出牌。

  药水：三格随身，左上角气血条右边。点击即用，
  不占灵力也不占出牌次数。战后掉落（普通三成、精英六成半、
  守卷之兽必掉），满三格就不再掉。十种，从群体上毒到瞬间回血都有。

  符箓共 91 张。其中两张是「X 费」——
  焚墟（群体伤害）与凝气（护甲）：打出时消耗全部灵力，
  有多少灵力就放多大，费用印上写的是 X。

  五行笔意（这是这一版的核心）：
    每张符箓都属五行之一，标在卡面圆顶。
    连续打出三张同属，就会「成势」，额外落一笔：
      金  对所有敌人造成 5 点伤害
      木  对所有敌人施加 2 层中毒
      水  获得 8 点护甲
      火  对所有敌人施加 3 层灼烧
      土  抽 1 张牌
    中间换属会从 1 重新数。笔意可以跨回合攒着，不必一回合打完。
    左下角灵力球外那圈五色环就是当前笔意，旁边写着进度。

  异兽共 23 种。各有特性，逼你换打法：
    狰  反噬    每次受击反弹 1 点
    讙  闪身    30% 概率躲开攻击
    毕方 免疫火  还会每回合给你上灼烧
    穷奇 卸力    每场第一次受伤减半
    鯥  免疫虚弱  ·  九婴 每回合自愈
    蛮蛮 治疗同伴  ·  天狗 攻击吸血
    英招 越打越猛（每次攻击叠力量）
    ……
  守卷之兽到半血会进入二阶段，换招、加力量，还会说话。

  法宝共 36 件，分六套（剑意/焚天/蚀骨/不动/通玄/镇印），
  集齐 3 件触发共鸣。

  歇脚三选一：养气（回血）、修符（升级）、铭刻（给单张牌加篆文）。
  铭刻六种：锋/轻/护/迅/回/蚀，刻什么决定这张牌的角色。

  记不住？标题页有「要诀」，地图左上角也有，或按 F1 / H。
  战斗中按 ESC 也能从暂停面板里打开。

  三卷：南山经 → 西次经 → 北山经，
  每卷末有守卷之兽。地图上散落着残页（共 9 页），
  集得越多，越接近师父留下的真相，也越能解锁后两个结局。

【场景】
  每只异兽都有自己的地盘：大泽、密林、火原、山岭、荒谷、雪岭、空界。
  战斗开场按首只敌人取景，同一个 Boss 换个地方打，画面就不一样。
  鬼市是一条夜里的长街，歇脚是山壁下的一堆炭火。
  二十六件事各有插画，挂在事件页左边，像一幅小卷。
  图鉴里每只异兽都注明「出没于」哪一处，并列出它的性情（反噬/闪身/免疫火……）。
  地图上只有下一步可走的地方亮着朱砂圈，其余压淡——不用再数连线。
